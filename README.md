# RPGMaker-Cheatah
Universal Game Injector &amp; Dynamic Memory Scanner injects cheat and inspection menus into HTML5 (RPG Maker MV/MZ) and Ren'Py games. It features safe auto-backups, variable freezing, dynamic delta tracking, and mathematical curve fitting to reverse-engineer obfuscated memory formulas. Powered by a Tkinter GUI and non-intrusive runtime scripts.
